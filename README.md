# 자린고비

사고 싶은 물건을 굴비처럼 홈에 걸어두고, 소비를 참은 날마다 목표 금액에 가까워지는 절약 앱.

- 배포 주소: https://jaringobi-blond.vercel.app
- 파일 구성
  - `index.html` — 앱 전체 (화면, 스타일, 동작)
  - `sample.jpg` — 발표용 예시 사진 (소니 WH-1000XM5)
  - `gulbi.svg` — 사진을 올리지 않았을 때 걸리는 기본 굴비 그림

## 수정하는 법

GitHub에서 `index.html`을 열고 연필(✏️) 버튼으로 고친 뒤 **Commit changes**를 누르면,
Vercel이 연결되어 있을 때 1분 안에 배포 주소에 반영돼요.

- 문구 바꾸기: `index.html`에서 바꾸고 싶은 한국어 문구를 검색해서 고치면 돼요.
- 발표용 예시 바꾸기: `loadSample` 부분의 상품 이름(`name`)과 가격(`price`)을 고치고, 사진은 `sample.jpg`를 새 파일로 바꿔 올리면 돼요.

기록은 서버가 아니라 각 사용자의 브라우저에 저장돼요. 로그인 화면은 발표용이라 실제 계정을 확인하지 않아요.
